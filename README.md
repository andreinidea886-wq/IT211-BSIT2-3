# Laboratory Activity 01
## Grade Classifier

### Course
IT 211 - Object-Oriented Programming

### Section
BSIT 2-1

---

## Problem

Create a Java program that accepts a student's numerical grade and displays the corresponding remark.

Use the following classification:

| Grade | Remark |
|---|---|
| 90-100 | Excellent |
| 80-89 | Very Good |
| 75-79 | Passed |
| Below 75 | Failed |

### Example

Input:

85

Output:

Very Good

---

## Requirements

Your program must:

1. Be written in Java.
2. Use standard input.
3. Accept a numerical grade.
4. Determine the correct remark.
5. Display the remark.
6. Compile successfully.
7. Follow proper Java syntax and formatting.

### Suggested Class

Use:

`Main`
